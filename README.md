# 穿搭工作台（PWA 网页版）

一个移动端优先的穿搭工作台，已做成**可安装到手机主屏**的 PWA 网页应用。

## 功能回顾
- **首页**：瀑布流展示 ≥50 条热门穿搭（抖音/小红书角标 + 点赞），每天自动更新。
- **穿搭方案**：顶部「最常穿的穿搭」长方形方格（每周更新）+ 下方春夏秋冬四个正方形方格。
- **个人主页**：
  - 上传衣物：从相册选图 → 前端 AI 自动抠图换白底 → 加入 11 个服饰分类之一。
  - 搭配衣物：左上角小圆弹出服饰分类浮层，拖拽衣物到白底画布拼搭，底部「添加」存到四季，右下角「完成」退出。

## 本地预览
```bash
cd <项目目录>
python3 serve.py          # 默认 8080 端口
# 浏览器打开 http://localhost:8080/
```
> 用 `serve.py` 而非 `python -m http.server`，因为它对 `.js`/`.json` 配置了正确的 MIME，否则 ES Module / Service Worker 会报错。

## 安装到手机（两种方式）

### 方式 A：局域网 + 真机（推荐，零成本）
1. 电脑和手机连**同一个 WiFi**。
2. 电脑运行 `python3 serve.py`。
3. 查电脑局域网 IP（如 `192.168.1.20`），手机浏览器打开 `http://192.168.1.20:8080/`。
4. 安卓 Chrome：点右上角 `⋮` → **「安装应用」/「添加到主屏幕」**。
   苹果 Safari：点底部分享图标 → **「添加到主屏幕」**。
5. 桌面即出现「穿搭工作台」图标，点开就是全屏 App。

> 注意：手机浏览器「添加到主屏」在 **HTTPS** 下体验最佳；部分安卓在 HTTP 局域网下也能装，若提示无法安装，用方式 B。

### 方式 B：部署到公网 HTTPS（永久可装、可分享）
任选一个免费静态托管，把**整个项目目录**拖上去即可：
- **GitHub Pages**：推到仓库 → Settings → Pages → 选分支根目录。
- **Vercel / Netlify**：拖拽目录，自动识别静态站点。
- **Cloudflare Pages**：同上。
部署后拿到 `https://xxx` 地址，手机打开 → 添加到主屏。

## 数据说明
- 衣物、搭配方案存在**手机浏览器本地**（IndexedDB），不上传服务器，隐私安全。
- 换设备 / 清缓存数据不互通；后续如需云同步可加轻量后端。

## 目录结构
```
index.html              入口
serve.py                本地静态服务器（带正确 MIME）
src/
  main.js              Tab 路由 + PWA 安装引导
  styles.css           全局样式（移动端）
  pages/               首页 / 方案 / 个人主页 / 搭配画布
  lib/                 IndexedDB、分类、抠图、首页数据
public/
  manifest.json        PWA 清单
  sw.js                Service Worker（离线缓存）
  icon-192.png/512.png 安装图标
scripts/crawler/       抖音/小红书爬取参考脚本 + 说明
```

## 抠图说明
- 首次使用「上传衣物」会从 CDN 加载 AI 抠图模型（几十 MB，需联网），之后浏览器缓存可离线。
- 模型加载失败会自动降级为「亮度去背」，仍可换白底。
